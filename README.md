# 🛒 Web Scraping Alkomprar - Selenium & CI/CD

![CI-CD Alkomprar Scraping](https://github.com/Davidcalle77/alkomprar-scraping-selenium/actions/workflows/ci-cd.yml/badge.svg)

Proyecto de automatización y extracción de datos de productos de Alkomprar utilizando Selenium, estructurado de forma modular con pruebas unitarias y validación continua mediante GitHub Actions.

## Estructura del Proyecto

- `scraper/`: Módulos de extracción (`extractor.py`) y procesamiento de precios (`precios.py`).
- `tests/`: Pruebas unitarias automáticas (`test_scraper.py`).
- `notebooks/`: Cuadernos de análisis explicativos en Google Colab.
- `.github/workflows/`: Pipeline de Integración Continua (`ci-cd.yml`).

## Instalación y Ejecución

1. Clonar el repositorio:
   ```bash
   git clone [https://github.com/Davidcalle77/alkomprar-scraping-selenium.git](https://github.com/Davidcalle77/alkomprar-scraping-selenium.git)
   cd alkomprar-scraping-selenium
   ```
